# AgendaCan 🐾
**Gestión y Ficha para Peluquerías Caninas y Spas de Mascotas**

AgendaCan es una aplicación moderna y completa diseñada para simplificar el día a día de peluquerías caninas, barberías de mascotas y spas.

## ✨ Funcionalidades Principales

- 📅 **Agenda Interactiva**: Gestión de turnos diarios con horarios, control de capacidad simultánea y estados en tiempo real.
- 🐶 **Ficha Médica y Estética de Mascotas**: Perfiles detallados con historial de visitas, temperamento, alergias, cuidados especiales y fotos antes/después del servicio.
- 🔁 **Fidelización y Retención**: Detección de clientes con intervalos cumplidos y avisos con plantillas personalizadas de WhatsApp a un clic.
- ⚙️ **Configuración del Salón**: Gestión de servicios, precios, horarios de atención, staff y políticas del negocio.
- 📱 **Diseño Responsive**: Optimizado para dispositivos móviles, tablets y escritorios.

## 🚀 Despliegue en Vercel

Este proyecto ya está configurado con `vercel.json` para despliegue instantáneo.

### Opción 1: Despliegue desde GitHub (Recomendado)
1. Conecta este repositorio en tu cuenta de GitHub.
2. Ve a [Vercel](https://vercel.com/) e inicia sesión.
3. Haz clic en **"Add New..."** > **"Project"**.
4. Selecciona tu repositorio de GitHub `agendacan`.
5. Vercel detectará automáticamente **Vite**:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
6. Haz clic en **Deploy**. ¡Listo en menos de 1 minuto!
